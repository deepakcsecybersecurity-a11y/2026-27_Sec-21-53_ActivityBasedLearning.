##### 4\. Attendance Recovery Computation (PDF Task 12)

START

Input classes attended, total classes conducted and target percentage.

If attendance details are invalid, display an error.

Else if target is not above 0 or is greater than 100, display an error.

Otherwise, set extra = 0.

While (attended + extra) × 100 / (conducted + extra) < target:

Increase extra by 1.

Display the number of consecutive classes to attend.

STOP
