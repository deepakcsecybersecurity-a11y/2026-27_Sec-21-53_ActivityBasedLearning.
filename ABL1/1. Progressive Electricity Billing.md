#### 1\. Progressive Electricity Billing (PDF Task 2)

###### START

Input electricity units.

If units < 0, display an invalid-units message.

Otherwise:

If units <= 100, bill = units × 2.

Else if units <= 200, bill = 100 × 2 + (units − 100) × 3.

Else, bill = 100 × 2 + 100 × 3 + (units − 200) × 5.

Add the fixed charge of Rs. 50 to the bill.

Display the electricity bill.

###### STOP
