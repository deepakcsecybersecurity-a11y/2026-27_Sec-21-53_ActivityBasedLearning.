##### 2\. Retail Billing with Discounts (PDF Task 7)

START

Input the number of products; set subtotal = 0.

Repeat for each product:

Input product name, price and quantity.

Calculate amount = price × quantity.

Add amount to subtotal and display the amount.

If subtotal >= Rs. 1000, discount = 10% of subtotal; otherwise discount = 0.

Calculate after\_discount = subtotal − discount.

Calculate tax = 5% of after\_discount.

Calculate total = after\_discount + tax.

Display subtotal, discount, tax and final bill.

STOP
