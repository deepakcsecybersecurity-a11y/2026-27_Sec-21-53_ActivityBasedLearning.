##### 8\. Password Policy Validation Engine (PDF Task 29)

START

Input the password.

Set has\_upper, has\_lower and has\_digit to False.

For each character in the password:

If it is uppercase, set has\_upper = True.

If it is lowercase, set has\_lower = True.

If it is a digit, set has\_digit = True.

Set valid = True.

If length is below 8, display the length requirement and set valid = False.

If any required character type is missing, display its message and set valid = False.

If valid is True, display that the password meets the example rules.

Otherwise, display that it does not meet the example rules.

STOP
