##### 5\. ATM Transaction Sequence Simulation (PDF Task 13)

START

Input opening balance and number of transactions; create an empty transaction list.

Repeat for each transaction:

Display Deposit and Withdraw options.

Input choice and amount.

If amount <= 0, reject and record the transaction.

Else if choice = 1, add amount to balance and record deposit.

Else if choice = 2:

If amount <= balance, subtract it and record withdrawal.

Otherwise, reject for insufficient balance.

Otherwise, display invalid choice and record it.

Display all transaction records and the final balance.

STOP
