##### 9\. Student Marks Matrix Analysis (PDF Task 42)

START

Initialize the marks matrix, student names and subject names.

For each student:

Set total = 0.

Add all subject marks for that student to total.

Calculate and display the student's average.

For each subject:

Set total = 0.

Add that subject's marks for all students.

Calculate and display the subject average.

Set top\_index = 0.

Compare each student's total with the current top student's total; update top\_index if higher.

Display the name of the top performer.
