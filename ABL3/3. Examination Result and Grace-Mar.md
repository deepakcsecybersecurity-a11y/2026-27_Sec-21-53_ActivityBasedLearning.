##### 3\. Examination Result and Grace-Mark Validation (PDF Task 11)

START

Create an empty marks list and the subject list: English, Maths and Python.

For each subject, input the mark.

If the mark is outside 0 to 100, display an error and ask once again.

Store the mark in the marks list.

Set failed = 0.

For each stored mark:

If 32 <= mark < 35, add 3 grace marks.

Add the resulting mark to final marks.

If the resulting mark < 35, increase failed by 1.

Display final marks.

If failed = 0, display PASS; otherwise display FAIL.

Display the number of failed subjects.

STOP
